# 👥 Team Directory – React Mini Project

A simple Team Directory application built with **React.js** to understand the fundamentals of Props and reusable components.

## 📌 About the Project

The main purpose of this project is to practice how **Props work in React** by passing team member information from a parent component to reusable child components.

Instead of creating separate components for every team member, I created a reusable component that receives different data through props and dynamically displays each member's information.

## 🎯 What I Learned

- Understanding how Props work in React.
- Passing data from parent components to child components.
- Receiving props using destructuring.
- Creating reusable React components.
- Rendering dynamic data using the `map()` method.
- Understanding component-based architecture.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite

## 💡 Key Concept Practiced

**Props in React**

Props allow components to receive data from their parent components, making it possible to create reusable and dynamic UI elements.
